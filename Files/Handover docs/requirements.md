## 1. Project Objective

The Northstar Support Deflection Chatbot is an MVP designed to reduce
manual support ticket handling by automatically answering repetitive
customer questions.

## 2. MVP Scope

The chatbot will support two ticket categories:

1. Order Status
2. Returns & Refunds

Stock Availability is outside the MVP scope.

## 3. Order Status

The chatbot should handle questions such as:

- Where is my order?
- Has my order shipped?
- When will my order arrive?

For an order-status request, the chatbot should:

1. Identify the customer's request.
2. Request an order number when necessary.
3. Look up the order.
4. Return the order status.
5. Provide shipping information where available.
6. Provide the estimated delivery date where available.

## 4. Returns & Refunds

The chatbot should handle questions such as:

- How do I return this?
- Is my order eligible for return?
- When will I receive my refund?

The chatbot should provide appropriate information about:

- Return eligibility
- Return process
- Refund processing
- Expected refund timeline

## 5. Unsupported Questions

If the customer's question is outside the MVP scope, the chatbot
should clearly tell the customer that it cannot currently handle
that request and provide an appropriate fallback message.

## 6. MVP Success Criteria

The MVP should demonstrate that:

- Order-status questions can be answered automatically.
- Returns and refund questions can be answered automatically.
- Customers can interact with the chatbot through the user interface.
- Invalid or unsupported requests receive a clear response.

## 7. Definition of Done

The supported chatbot scenarios and MVP scope are documented and
agreed by the team.
